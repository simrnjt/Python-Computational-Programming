# what is Python?

Python is a hight level, interpreted programming language known for it's simplicity, redability and versatality.

## Key feature of Python

1. Interpreted - python is an interpreted programming language. interpreted programming lauguage means, we use an interpreter to execute/run the python code line by line. interpreter always runs the code line by line. No compilation is required.
2. Dynamically or loosely typed - python is a loosely typed programming language, i.e. we don't need to explicitly mention the variable types(as we do in other programming languages using the data types).
3. High-level language - it's syntax is like english only.
4. object-oriented programming language - in python we can write resuable and organized code.
5. cross-platform - python code runs on windows, Mac, linux operating systems.

## Limitations of Python

1. slower that c/c++/java because python is an interpreted programming language.
2. GIL (Global Interpreter Lock) - limites the true multithreading.
3. high memory usage as compared to other low level programming languages.

## Python - A programming language or a scripting language

1. python is a general purpose programming language that is often used as a scripting language.
2. in the ai-ml domain, python is used as a scripting language, when we need to clean the data and preprocess the data
3. python as a scripting langauge is also used for automation or system level tasks

## data types in python

python data types are divided into two categories

1. primitives
2. containers

primitive (or fundamental) data types are the basic building blocks in python. they are called as primitive data types because they represent a single value.

primitives includes:

1. Integer
2. Boolean
3. Float
4. String 
5. None

containers are also called as data structures in python because they hold multiple pieces of data together.
Container includes:

1. List
2. Dictionary
3. tuple
4. set

## literal

a literal is a value. for example: 10, 12.5, 'k', etc.

## variable

a variable is a name pointing to that value. for example: a = 12, here 'a is a variable' and '12 is a literal'. A variable is python is defined through assignment only. there is no concept of declaring a variable outside of that assignment.
