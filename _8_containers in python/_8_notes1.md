# containers in python

in python, containers are built in data types that hold collection of data, not a single data item. they allow you to group multiple values together into a single object, making it easier to manage, organize and manipulate the data

in python, string str is conceptually treated as a primitive datatype because it's built-in, mutable and used as a basic value, but technically, it's an objecet and a sequence of characters, so not a primitive in the low-level sense.
