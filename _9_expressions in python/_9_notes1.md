# Expressions in Python

An expression is a combination of operator and operands that is interpreted to produce some other value.

In any prgramming language, an expression is evaluated as per the prenedence and associativity of its operators.

So that if there is more than one operator in an expression, their precedence decides which operation will be performed first.

If an expression contains two or more operators with the same precedence then Operator Assaciativity is used to determine their order of execution. It can either be Lelt to Right or from Right to Left.

## Operator types in python

1. Exponent : **
2. Remainder: %
3. Multiplication: *
4. Float Division: /
5. Integer Division or Floor Division: //
6. Addition: +
7. Subtraction: -
